# Contribute

Read the [development guide](docs/DEVELOPMENT.md). Keep each change focused on one problem.

Use short, clear English for labels and instructions. Use the same word for the same control. Explain a user action before its result. Do not claim certified STE compliance.

Code changes and public pull requests require the publisher's written permission under the current license. If authorized, run `npm run check`, `npm test`, and `npm run build` before submission. For a player change, also check playback, pause, forward seek, backward seek, and all three sentence-sync modes.

Use local fixtures for tests. Do not commit account data, API keys, browser profiles, real film files, or private player reports.

Describe the problem, the new behavior, and the checks you ran. Include a screenshot for a visible change.

The public source is available for viewing and personal use. The current license does not grant permission to modify or redistribute it. Report bugs through Issues or the support link. Agree on permission and contribution rights with the publisher before submitting code. Read [license scope](docs/LICENSING.md).
