# Contribute

Read the [development guide](docs/DEVELOPMENT.md). Keep each change focused on one problem.

Use short, clear English for labels and instructions. Use the same word for the same control. Explain a user action before its result. Do not claim certified STE compliance.

Code changes are permitted for purposes covered by PolyForm Perimeter. Before a contribution, run `npm run check`, `npm test`, and `npm run build` before submission. For a player change, also check playback, pause, forward seek, backward seek, and all three sentence-sync modes.

Use local fixtures for tests. Do not commit account data, API keys, browser profiles, real film files, or private player reports.

Describe the problem, the new behavior, and the checks you ran. Include a screenshot for a visible change.

Report bugs through Issues or the support link. Only submit code you have the right to contribute under PolyForm Perimeter. Providing a competing product to others is prohibited. Read [license scope](docs/LICENSING.md).
