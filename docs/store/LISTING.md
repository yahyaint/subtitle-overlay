# Store listing draft

## Name

Subtitle Overlay

## Short description

Find, save, and sync subtitles over browser video. Change the font, color, size, background, and shadow.

## Full description

Read. Sync. Watch.

Add external subtitles to a video in your browser. Use a local file or search OpenSubtitles. Use clear Inter text and a marine-blue tool rail to find, save, and adjust subtitles. File buttons stay at the bottom of the popup. A larger clock and delay field help you set the timing on the video. Bottom subtitles move above readable player controls, then return to your chosen position.

Find and load:
- Load SRT, WebVTT, ASS, SSA, or text SUB files.
- Open subtitle files inside ZIP and gzip archives.
- Search OpenSubtitles through its website or API.
- Get an editable film title suggestion from the player.
- Group readable player subtitle tracks by language. Import lines, readable style, and position for overlay adjustments and saving.

Set the timing:
- Move subtitles earlier or later.
- Sync with one, two, or three sentences.
- Use two or three sentences to correct steady timing drift.

Import readable player text style and position. Restore the captured appearance in Text style without changing timing. Save keeps the original appearance with your settings. Some player styles are not readable.

Set the text style:
- Change the font, size, color, and height.
- Change the background color and opacity.
- Change the shadow color, opacity, blur, and offset.

Save for later:
- Keep subtitles in a local library grouped by film.
- Save timing and text settings with each subtitle.
- Browse saved Films or Shows. Select a show, season, and episode, then load a saved file.

Start a film, open the extension, and select Show overlay. Local files need no account. API search needs your OpenSubtitles key. Website search needs no extension API key.

Some players do not expose a readable film clock. If asked, show the player's own controls. ASS and SSA styles and effects are not rendered. Image subtitles and RAR files are not supported. Files and extracted subtitle data have a 2 MB limit.

This is an independent extension. It is not affiliated with Disney+, OpenSubtitles.

The extension is free to use. The optional Tip link opens https://yahyanabil.com/support. A tip is not needed to use any feature.

Version 0.8.12 is the current stable release. Live player compatibility and provider delivery can vary.
