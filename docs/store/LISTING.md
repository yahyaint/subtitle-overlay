# Store listing draft

## Name

Subtitle Overlay

## Short description

Find, save, and sync subtitles over browser video. Change the font, color, size, background, and shadow.

## Full description

Read. Sync. Watch.

Add external subtitles to a video in your browser. Use a local file or search OpenSubtitles. Keep the controls on the video so you can adjust the subtitles while you watch.

Find and load:
- Load SRT, WebVTT, ASS, SSA, or text SUB files.
- Open subtitle files inside ZIP and gzip archives.
- Search OpenSubtitles through its website or API.
- Get an editable film title suggestion from the player.

Set the timing:
- Move subtitles earlier or later.
- Sync with one, two, or three sentences.
- Use two or three sentences to correct steady timing drift.

Set the text style:
- Change the font, size, color, and height.
- Change the background color and opacity.
- Change the shadow color, opacity, blur, and offset.

Save for later:
- Keep subtitles in a local library grouped by film.
- Save timing and text settings with each subtitle.
- Load saved files without another search.

Start a film, open the extension, and select Open controls. Local files need no account. API search needs your OpenSubtitles key. Website search needs no extension API key.

The extension also helps you find external audio sources. You can add an audio catalog or website search link. Audio discovery does not replace or sync the player's audio.

Some players do not expose a readable film clock. If asked, show the player's own controls. ASS and SSA styles and effects are not rendered. Image subtitles and RAR files are not supported. Files and extracted subtitle data have a 2 MB limit.

This is an independent extension. It is not affiliated with Disney+, OpenSubtitles, or the audio sources it links to.

Version 0.7.9 is a preview. Live player compatibility and provider delivery can vary.
