# Subtitle Overlay 0.8.2 preview

Use a wider 440 px popup. Player status and film-source hints use plain helper text without a side bar. Marine backgrounds, action colors, and gold accents are less saturated. The logo uses the same muted marine color.

Subtitle colors remain user settings. Subtitle loading, saved presets, timing, and sentence sync are unchanged.

Download `subtitle-overlay-0.8.2-release.zip`. Extract it and load its extension folder. For an existing installation, reload the extension and refresh film tabs. Store upload uses `subtitle-overlay-0.8.2-chrome-web-store.zip`. Store submission remains separate.
