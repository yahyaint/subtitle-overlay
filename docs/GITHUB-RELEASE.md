# Subtitle Overlay 0.8.0 preview

New Design gives the popup and video controller a shared tool rail with marine blue, amber, and silver. Inter is bundled for app controls. Find, Saved, and Settings have clear views. Open controls and Load file stay at the bottom of the popup. The controller has a larger clock and delay field, separate Save and Delete icons, and grouped sync and text controls.

The playback clock, one-, two-, and three-sentence sync, player-subtitle import, original-style restore, saved settings, search, and download handling keep their existing behavior. This release adds no permissions or remote code.

Download `subtitle-overlay-0.8.0-release.zip`. Extract it. In `chrome://extensions`, turn on Developer mode, select Load unpacked, and select its extension folder.

For an existing installation, reload the extension and refresh each film tab. Store upload uses `subtitle-overlay-0.8.0-chrome-web-store.zip`. Store submission remains a separate step.

Local tests use Chromium and sample video. Live signed-in playback and store acceptance remain separate checks. Disney+ playback, seeking, and sentence sync were confirmed by the publisher in Vivaldi with 0.7.10. No new live-service test is claimed for this design release.
