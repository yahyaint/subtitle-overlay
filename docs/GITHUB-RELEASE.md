# Subtitle Overlay 0.8.9

The video controller now has an easy Close button at the bottom of its tool rail. Close hides the controls while subtitles keep playing. The loaded file, sync points, and text settings stay in place.

The extension action is now Show overlay. Use it to show the controls again. The publisher reports that the current build works in their setup. This release is marked stable.

Download `subtitle-overlay-0.8.9-release.zip`. Extract it and load its extension folder. For an existing installation, reload the extension and refresh film tabs. Store upload uses `subtitle-overlay-0.8.9-chrome-web-store.zip`.

No new permissions. MIT license. Live player and provider support can vary.
