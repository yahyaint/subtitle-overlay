# Subtitle Overlay 0.8.3 preview

Fix the browser action popup width. Its document and body use an intrinsic 440 px width instead of a width limited by the initial viewport. This prevents a narrow starting viewport from squeezing labels and controls. The footer fits when the browser limits popup height; only the workspace scrolls. Remove the decorative three-bar mark from the header.

Subtitle loading, saved presets, timing, and sentence sync are unchanged.

Download `subtitle-overlay-0.8.3-release.zip`. Extract it and load its extension folder. For an existing installation, reload the extension and refresh film tabs. Store upload uses `subtitle-overlay-0.8.3-chrome-web-store.zip`. Store submission remains separate.
