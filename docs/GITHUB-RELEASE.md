# Subtitle Overlay 0.8.8 preview

Saved subtitles now has separate Films and Shows views in the popup and video controller. For a show, select the show, season, and episode. Episode names appear when available. Season 0 appears as Specials.

Existing subtitle files and saved settings remain in place. Older titles such as `X-Men 97 S01E04` are recognized as episodes. Tracks for the same episode appear together across languages and release years. Automatic routing selects the saved show episode when the player identifies it.

Download `subtitle-overlay-0.8.8-release.zip`. Extract it and load its extension folder. For an existing installation, reload the extension and refresh film tabs. Store upload uses `subtitle-overlay-0.8.8-chrome-web-store.zip`.

Four focused local browser suites pass: saved-library, design, automatic routing, and main integration. Store images and ZIP packages are refreshed.

No new permissions. MIT license. This is a preview release. Live player and provider support can vary.
