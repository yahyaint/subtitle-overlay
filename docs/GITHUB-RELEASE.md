# Subtitle Overlay 0.8.7 preview

The video controller could show an old saved search while the popup showed the current film. A delayed settings response caused this error. The current film and year now stay selected.

The popup and controller share the search title, year, language, method, and website link for the active tab. Edits remain in place while the same film plays. A new film updates the title and year. Requests from an old page are rejected.

The Player subtitles panel stays first. Online search now has clear spacing below it. Both views show the source of the detected title below the title field.

Download `subtitle-overlay-0.8.7-release.zip`. Extract it and load its extension folder. For an existing installation, reload the extension and refresh film tabs. Store upload uses `subtitle-overlay-0.8.7-chrome-web-store.zip`.

All nine local integration suites pass, including seeking and all three sentence-sync modes. Store images and release packages are refreshed.

No new permissions. MIT license. This is a preview release. Live player and provider support can vary.
