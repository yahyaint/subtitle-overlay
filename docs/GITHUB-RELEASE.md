# Subtitle Overlay 0.8.6 preview

Player subtitles is the first panel in Find. New videos and tracks update sooner. Import supports public caption files from custom menus, open shadow roots, Video.js, JW Player, and Artplayer. Series routes can supply season and episode numbers.

Files load only after Import. No new permissions are required. Public caption data must be readable. On the tested Movy episode, the site's own menu reported no subtitles available; the extension cannot supply missing tracks. Cross-origin frame players are not supported by this change.

Download `subtitle-overlay-0.8.6-release.zip`. Extract it and load its extension folder. For an existing installation, reload the extension and refresh film tabs. Store upload uses `subtitle-overlay-0.8.6-chrome-web-store.zip`.
