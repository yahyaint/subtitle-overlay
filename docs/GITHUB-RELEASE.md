# Subtitle Overlay 0.8.1 preview

Remove external dubbing audio discovery. The popup no longer shows Find dub audio. Audio pages, provider routes, catalogs, examples, and source data are removed. Updates clear the retired audio preferences and session tokens. Saved subtitles and OpenSubtitles access remain.

Subtitle setup has its own stylesheet. Film matching retains the same title normalization. Inter and the marine-blue design remain.

Download `subtitle-overlay-0.8.1-release.zip`. Extract it and load its extension folder. For an existing installation, reload the extension and refresh film tabs. Store upload uses `subtitle-overlay-0.8.1-chrome-web-store.zip`. Store submission remains separate.
