The current distribution uses [PolyForm Noncommercial 1.0.0](../LICENSE). The license is a standard software license. Its text is unchanged from the [official file](https://polyformproject.org/licenses/noncommercial/1.0.0.txt).

Personal entertainment and other permitted noncommercial uses are allowed. Commercial reuse or resale of new code needs separate written permission unless another valid license permits it. Ask through [the support page](https://yahyanabil.com/support). The copyright owner can offer a separate paid version or commercial license.

This is source-available software. The noncommercial license is not an open-source license. Read the full license for its permitted purposes, including its listed noncommercial organizations. This page is a summary.

## Earlier MIT releases

Version 0.8.10 and all earlier releases were published under MIT. Those permissions remain in effect for that code. They include commercial use and resale. Changing the current license or refreshing a release download cannot take those rights away.

New original additions first published after 0.8.10 use the current license. [The old MIT notice](../LICENSE-MIT-LEGACY.txt) is preserved for earlier code, not as an alternative license for later additions. The [notice](../NOTICE) explains this scope.

At the publisher's request, v0.8.9 and v0.8.10 release downloads and notes have updated licensing information. Their code stays unchanged. Their original Git tags stay unchanged. The notes distinguish the updated distribution from the original MIT publication.

## Bundled materials

The Inter font keeps its separate upstream license in `extension/INTER-LICENSE.txt`. Build and test dependencies keep their own licenses. The project license does not replace them.

## Payment

The code license does not create checkout, verify purchases, or set a store price. This build has no payment gate. The planned EUR 1 purchase requires an external payment processor and purchase verification. Chrome Web Store's built-in payments were discontinued; see [Google's technical notice](https://github.com/GoogleChrome/developer.chrome.com/blob/main/site/en/docs/webstore/cws-payments-deprecation/index.md).
