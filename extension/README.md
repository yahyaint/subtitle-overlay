# Subtitle Overlay

1. Open `chrome://extensions` or `edge://extensions`.
2. Turn on **Developer mode**.
3. Select **Load unpacked**. Select this folder.
4. Start a video. Open the extension and select **Open controls**.
5. Select **Load file**, or use **Find** to search OpenSubtitles.

Use **Sentence sync** to align one, two, or three sentences. Use **Text style** to change the font, color, size, background, and shadow. Select **Save** to keep the subtitle and its settings.

Downloads go to `Subtitle Overlay` inside your browser's download folder. Finish any website step or browser Save prompt first. Closing the search window stops tracking.

If the clock is unavailable, show the video's own controls. Some players do not expose a readable film clock.

ASS and SSA files use their text and timing. File styles and effects are not rendered. ZIP and gzip files are supported. Image subtitles and RAR files are not supported. The file and total extracted subtitle size limit is 2 MB.

To update: replace these files in the same folder, select **Reload** in the browser's extension page, then refresh the video tab.

In **Find → Player subtitles**, select **Use player** to keep the original display, or **Import** to load the selected file or copy readable lines, player style, and position into the overlay. Under **Text style**, **Restore player style** restores the captured appearance and keeps timing and sentence-sync points. Save keeps the original style with your current settings. Some player styles are not readable. **Restore player** restores caption choices changed by the extension. Only public tracks are listed; some players expose none.

Version 0.7.13 is a preview. The publisher confirmed Disney+ playback, seeking, and sentence sync in Vivaldi on Windows with 0.7.10. The new player-subtitle import still needs a live Disney+ check. Authenticated OpenSubtitles delivery still needs confirmation.
