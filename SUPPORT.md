# Get help

After the repository is published, use [GitHub Issues](https://github.com/yahyaint/subtitle-overlay/issues) for help.

Include the extension version, browser version, file format, and steps that show the problem. State whether the problem occurs after a seek.

For a clock problem, show the player's controls. Open **More settings → Save player report**. Check the report before you share it. A report can contain public player labels and element names. Remove information you do not want to share.

Do not post passwords, API keys, account tokens, browser profiles, or film files.
